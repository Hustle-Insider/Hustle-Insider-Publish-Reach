# Hustle Insider Publish Reach 🚀📡

[![npm](https://img.shields.io/npm/v/@hustle-insider/publish-reach)](https://npmjs.com/package/@hustle-insider/publish-reach)
[![PyPI](https://img.shields.io/pypi/v/hustle-insider-publish-reach)](https://pypi.org/project/hustle-insider-publish-reach)
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21778807.svg)](https://doi.org/10.5281/zenodo.21778807)

Hustle Insider Publish Reach helps businesses, founders and brands get their news and content in front of the right audience through strategic digital visibility and content distribution. Built by [HustleInsider.it.com](https://hustleinsider.it.com).

## Services

- **SEO & GEO Services** — Search engine and geographic optimisation for local and global reach
- **AI Visibility Services** — Optimising content for AI platforms, LLMs, and AI-powered search
- **Digital PR Services** — Strategic digital press release and media outreach distribution
- **Founder Branding** — Personal brand building for founders, executives, and entrepreneurs
- **Startup PR Distribution** — Press release and news distribution for early-stage startups
- **SaaS PR Distribution** — Product launches, feature announcements, and SaaS news distribution

## Features

- Publish Reach Score — evaluates content distribution strength and audience reach
- SEO & GEO Score — measures search engine and geographic optimisation
- AI Visibility Score — tracks presence across AI platforms and LLM responses
- Digital PR Score — evaluates press release quality and media pickup potential
- Founder Brand Score — measures personal brand authority and visibility
- Distribution Reach Score — assesses multi-channel content distribution coverage
- CLI support in Node.js and Python
- Benchmark dataset included (20 publish reach cases)
- Lightweight, publish-ready, minimal dependencies

## Quick Start

### Node.js

```bash
npm install @hustle-insider/publish-reach
npx hustle-insider-reach "brand-name" startup-pr 85 82 88 78 90 80
```

### Python

```bash
pip install hustle-insider-publish-reach
python -m publish_reach "brand-name" startup-pr 85 82 88 78 90 80
```
